# معمارية CSS الحديثة: من Container Queries إلى :has() و Subgrid

في السنوات الأخيرة، شهدت لغة CSS ثورة حقيقية نقلتها من مجرد لغة لتنسيق النصوص والألوان إلى بيئة هندسية متطورة تُمكّن المطورين من بناء واجهات مستخدم معقدة ومرنة بأقل قدر ممكن من كود JavaScript.

> **نقطة جوهرية:** مع إطلاق ميزات مثل Container Queries ومحدد الأب `:has()` وميزة `subgrid`، أصبح بإمكاننا الانتقال من التصميم المستجيب المتمركز حول الشاشة بأكملها (Viewport-driven) إلى **التصميم المستجيب المتمركز حول المكوّن ذاته (Component-driven Responsive Design)**.

---

## 1. نقلة نوعية: من Media Queries إلى Container Queries

لطالما اعتمدنا على `media queries` لتحديد كيف يظهر المكون بناءً على عرض شاشة الجهاز بالكامل (`window.innerWidth`). لكن ماذا لو وضعنا نفس المكون داخل شريط جانبي ضيق (Sidebar) وداخل منطقة المحتوى الرئيسي (Main Content) في نفس الصفحة؟

```
+-------------------------------------------------------------+
| Viewport Width: 1200px                                      |
|                                                             |
|  +--------------------+  +-------------------------------+  |
|  | Sidebar (300px)    |  | Main Content (900px)          |  |
|  |                    |  |                               |  |
|  | [ Card Widget ]    |  | [ Card Widget ]               |  |
|  | (يحتاج شكلاً عمودياً)|  | (يحتاج شكلاً أفقياً عريضاً)     |  |
|  +--------------------+  +-------------------------------+  |
+-------------------------------------------------------------+
```

باستخدام Container Queries، لا يهتم المكون بعرض الشاشة، بل يستجيب مباشرةً للمساحة المتوفرة داخل العنصر الحاوي له:

```css
/* 1. تعريف العنصر كحاوية */
.card-wrapper {
  container-type: inline-size;
  container-name: card-container;
}

/* 2. التنسيق الافتراضي (عمودي) */
.card-component {
  display: flex;
  flex-direction: column;
  gap: 1rem;
}

/* 3. الاستجابة عندما يتجاوز عرض الحاوية 450px */
@container card-container (min-width: 450px) {
  .card-component {
    flex-direction: row;
    align-items: center;
  }

  .card-thumbnail {
    width: 140px;
    height: 140px;
    flex-shrink: 0;
  }
}
```

## 2. محدد الأب السحري: `:has()` في الإنتاج

ظل مطورو الواجهات لسنوات طويلة يطالبون بطريقة لاستهداف العنصر الأب اعتماداً على حالة أبنائه دون الحاجة إلى JavaScript. أصبح ذلك واقعاً مدعوماً في جميع المتصفحات الحديثة عبر `:has()`.

### أمثلة عملية وقوية:

```css
/* 1. تغيير خلفية البطاقة إذا كانت تحتوي على شارة مميزة (Featured Badge) */
.card:has(.badge-featured) {
  border-color: var(--primary-color);
  box-shadow: 0 10px 25px -5px rgba(59, 130, 246, 0.15);
}

/* 2. تظليل النموذج عند تفعيل حقل غير صالح */
.form-group:has(input:invalid:focus) {
  animation: shake 0.3s ease-in-out;
}

/* 3. تطبيق نمط Grid خاص إذا كانت المقالة تحتوي على صورة غلاف */
.article-item:has(.article-cover) {
  grid-template-columns: 200px 1fr;
}
```

> **تحذير في الأداء:** لا تبالغ في تعشيش محددات `:has()` المعقدة في صفحات تحتوي على آلاف العناصر التفاعلية الثقيلة لتفادي استهلاك موارد إعادة الحساب (Style Recalculation).

---

## 3. محاذاة العناصر بدقة متناهية عبر `subgrid`

عند بناء بطاقات (Cards) في شبكة `grid` ذات رؤوس وعناوين ونصوص متفاوتة الطول، كان من المستحيل محاذاة الأزرار السفلية وأسماء المؤلفين في نفس المستوى بدقة عبر جميع البطاقات. تحل ميزة `subgrid` هذه المشكلة بجعل شبكة العنصر الابن ترث مسارات شبكة العنصر الأب:

```css
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 1.5rem;
}

.card-item {
  display: grid;
  /* المكون يرث صفوف الأب بدلاً من حساب صفوفه الخاصة */
  grid-template-rows: subgrid;
  grid-row: span 3;
}
```

## 4. مقارنة سريعة بين أساليب التجاوب

| المعيار | Media Queries التقليدية | Container Queries الحديثة |
| :--- | :--- | :--- |
| **نطاق القياس** | عرض شاشة المتصفح (`viewport`) | عرض العنصر الحاوي (`container`) |
| **إمكانية إعادة الاستخدام** | ضعيفة إذا تغيّر موضع العنصر | ممتازة، المكون مستقل تماماً |
| **التعقيد الهندسي** | كتابة شروط متعددة لكل صفحة | قاعدة تجاوب واحدة للمكوّن أينما وُضع |
| **الدعم في المتصفحات** | 100% مدعوم | مدعوم في كافة المتصفحات الحديثة (+95%) |

---

## 5. توصيات لبناء معمارية CSS مستدامة

1. **استخدم المتغيرات التفاعلية (CSS Custom Properties):** لتمرير الألوان والمسافات وجعل الثيم الداكن والفاتح سلساً وسريعاً.
2. **اعتمد على الحجم السائل (Fluid Typography):** عبر دالة `clamp()`:
   ```css
   font-size: clamp(1rem, 0.8rem + 1vw, 1.75rem);
   ```
3. **فصل الهيكل عن السلوك:** لا تعتمد على أسماء فئات تعكس مظهراً ثابتاً، بل اجعل الأسماء تعكس وظيفة المكون (Component Semantics).

> **خلاصة:** إن أدوات CSS الحديثة تمنحك اليوم القوة لبناء أنظمة تصميم (Design Systems) صلبة ومرنة تغنيك عن إرهاق كود الجافاسكريبت وتمنح المستخدم أداءً متفوقاً وتجربة تصفح غاية في السلاسة.
